# tallysvg

Tally CSV/TSV svg tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/tallysvg/

## Install / run

```bash
git clone https://github.com/theworker02/tallysvg.git
cd tallysvg
node src/cli.js
node --test
```
